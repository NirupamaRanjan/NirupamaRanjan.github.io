# NirupamaRanjan.github.io

Personal page + a CSS-only redesign of the CS6.302 (SSD, Monsoon 2026)
course page.

## Live pages
- Personal page: https://nirupamaranjan.github.io/
- Course page: https://nirupamaranjan.github.io/SSDcoursepage.html

## Files
- `index.html` — personal page (HTML, CSS, JS all in one file)
- `Images/` — gallery photos
- `SSDcoursepage.html` — original course page HTML, unmodified
- `SSDstyle.css` — new styling for the course page (CSS only, no HTML changes)

## Run locally
```bash
git clone https://github.com/NirupamaRanjan/NirupamaRanjan.github.io.git
cd NirupamaRanjan.github.io
python3 -m http.server 8000
```

Hosted via GitHub Pages, deployed from `main` / root.
